# Losowe opisy

Prosta strona statyczna z ośmioma kategoriami opisów. Siedem kategorii ma po 50 wpisów, a „Decide Poses” ma 20. Kliknięcie „Kopiuj” losuje jeden opis z wybranej kategorii i zapisuje go w schowku.

Treść znajduje się w pliku `data.js`. Strona nie potrzebuje serwera ani konta użytkownika.
