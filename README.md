# Losowe opisy

Prosta strona statyczna z kategoriami `app: pozer`, `PL dos and dont's` i `ENG dos and dont's`. Każda kategoria ma 50 opisów. Kliknięcie „Kopiuj” losuje jeden opis z wybranej kategorii i zapisuje go w schowku.

Treść znajduje się w pliku `data.js`. Strona nie potrzebuje serwera ani konta użytkownika.
